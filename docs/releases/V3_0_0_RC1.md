# Quick Presenter v3.0.0 RC1

Status: release preparation. Publication and final-package qualification are pending.

## Branches and candidate identity

- `v2.5` starts at `a930165` (the main HEAD before v3 integration). It is the
  maintenance target for 2.5.x fixes; forward-port applicable fixes to `main`.
- `main` becomes the v3 development and release integration target. The former
  `v3.0.0` branch remains available as history, not a second integration target.
- Candidate tag: `v3.0.0-rc.1`. Create it only on the selected, validated main
  revision. Do not move a published candidate tag; use `rc.2` for a replacement.
- Cargo, About, and CLI application version: `3.0.0`. macOS short version is
  `3.0.0`, Windows MSIX version is `3.0.0.0`, and Debian version is `3.0.0`.
  Keep the existing numeric native/Store packaging contract for this candidate.
  These version strings do **not** distinguish RC1 from a later final build.
  Always record the tag, full source SHA, workflow run, package hash, and Store
  build identity. Never reuse RC package evidence for changed final artifacts.
- The GitHub release must be marked **prerelease**, with Latest remaining on the
  stable release. Keep it a draft until the publication gates below are met.
  The changelog date remains Unreleased until actual publication.

## Candidate scope

Audience Live adds optional LAN and relay reactions/comments, QR-based joining,
comment history/logs, flowing and bubble overlays, Settings import/reset,
account recovery guidance, and an optional sticky QR. The Audience Window name,
Slint 1.19.0, and PDFium chromium/8165 are included. Control Protocol v1 remains
compatible. PDF playback remains the core function and must survive relay errors.

Official Relay staging and production are independently operated services.
Application preparation does not assert that either environment is qualified.
Do not embed deployment credentials or silently select a production relay.
