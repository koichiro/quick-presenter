The live CLI matrix includes status, navigation/boundaries, elapsed timer,
blackout, notes, compact/full slide and context, both export forms, close/reopen,
Marp/Beamer/Keynote/PowerPoint/Google Slides/long/mixed/generic-comment fixtures,
missing/invalid/encrypted-file error recovery, hot reload, and watch event types.
The count is 47 saved assertions, rather than the earlier development report's
51 assertions. It is not a claim that every manual UI item passed.

For cold startup, seed a fresh private startup record, verify NOT_RUNNING,
invoke `qp open` from an unrelated directory with a requested Japanese/space
filename, and independently poll Status until rendering and notes are ready.
All 17 independent attempts returned success and displayed the requested
3-page deck at page 1. Open times were 3.359–8.766 seconds; no BUSY, IPC_FAILURE,
or TIMEOUT occurred in that sequential matrix. Test-owned GUIs were terminated
after observation; these cases do not establish normal-quit persistence.

Each simultaneous pair returned one successful Open and one typed BUSY/exit 8
because another Open was in progress. All three pairs settled on the requested
deck in one session. Genuine concurrent mutations may return BUSY; automatic
mutation replay is intentionally excluded. An initial harness incorrectly
required both simultaneous mutations to succeed; that assertion was corrected
to the existing protocol contract, without changing production behavior.

An early harness run also exhausted its five-second process-cleanup wait after
successful startup. The owned process was subsequently gone. The full repeat
used a 30-second cleanup wait; production startup/IPC deadlines were unchanged.

## Manual and Store acceptance

The candidate was launched with the 12-page demo PDF for maintainer testing.
The maintainer confirmed normal operation of two-display X switching,
fullscreen, display disconnect/reconnect recovery and keyboard operation after
recovery on 2026-10-16. Monitor models, resolutions, mixed-DPI and display
rearrangement were not separately recorded. This is a maintainer-confirmed
candidate result, not certified Store-installed acceptance.

Windows Narrator was then started for this test. Its Speech recap showed actual
announcements for Open, First Page, Previous Page, Next Page, Last Page,
Fullscreen and Black as buttons; File/Navigate/View/Window/Help as menu items;
the document filename, timer/clock, page count, Notes and the read-only notes
text. This was observed in Narrator output, beyond simply finding UI Automation
names. Narrator item navigation traversed those controls. Narrator was stopped
afterward; no startup preference or speech/privacy setting was changed.

After Narrator had focused the read-only notes, a native-key probe found a
focus limitation: Space advanced page 1 to 2, but Return left page 2 unchanged
in the presenter; Return in the slide window advanced to page 3, and Right in
the presenter with notes focused left page 3 unchanged. Independent CLI Status
confirmed the page values. Focusing the slide window is the observed navigation
workaround. This limitation belongs to the deferred keyboard/focus baseline
#339; it is not a pass for every presenter key variant and is not fixed by this
documentation-only change.

The rendered slide and preview images were announced generically as images;
spoken slide content was not established. This is a limited screen-reader
smoke result, not complete nonvisual workflow acceptance. Thumbnail semantics,
dynamic announcements, disabled/current states, every Tab/Space activation and
all scaling combinations remain in the broader accessibility baseline #339.
The speech log also contained unrelated desktop output, so only the
app-specific observations are transcribed in the evidence directory.

Remaining certified-installation work includes trust/Start Menu/taskbar/Alt+Tab,
About, registered CLI alias and alias-triggered startup, picker/Recent/Open With,
all keyboard/button/focus/recovery variants, notes/resize/scroll readability,
normal-quit/startup restoration, upgrade/uninstall, installed package identity
and renderer isolation, WACK/certification, and certified-version/SBOM identity.
The confirmed physical recovery and limited Narrator results above satisfy the
corresponding candidate observations; retain mixed-DPI/rearrangement and the
remaining accessibility matrix as unrecorded. No waiver is introduced by this
report.

The published release's `chromium/8076` pin-review limitation and existing
`bincode`/`ttf-parser` maintenance warnings remain unchanged. This candidate is
the same release source, not a new dependency-security qualification. The
release audit passed with no ignored vulnerability advisories. Corresponding
source is the exact published release revision, with Cargo.lock and vendored
modifications; the extracted package includes its source-offer and licenses.
