Read the demo transcript

Slide 1. Welcome to this short Quick Presenter demo. Each slide has a speaker note containing the words you are hearing. The demo reads those notes aloud, waits for the speech to finish, and then moves to the next slide.

Slide 2. The audience sees only the key ideas on this slide. The full explanation lives in the speaker notes embedded in the PDF. This demo reads that explanation word for word. It does not invent an explanation or read the bullet points instead.

Slide 3. Notice that this slide stays on screen while the narration is playing. Only after the speech finishes does the demo ask Quick Presenter to move forward. If speech playback fails, the demo stops without sending a page change. Keep presentation control exclusive while the demo runs.

Slide 4. That is the end of the demo. The presentation will stay on this final slide. To make your own version, edit the slide text and the speaker notes in the Markdown source, then export a new PDF with Marp's PDF notes option enabled. Thank you for listening.

The AI agent interface in 2.0

Read the deck. Control the flow. Observe changes.

A stable CLI gives external tools access to deck information and presentation operations. Conversation and narration are two examples of what you can build.

Read

Give agents the whole deck.

Export text and speaker notes from every page as JSON without changing the displayed slide. Use qp context --full --json for current and next page context. Images, diagrams, and OCR are not included.

qp export --json
Control

Choose the next action.

Open a PDF, select a page, or advance. Pages are one-based; 3 below is a syntax example, not a fixed destination for any question.

qp goto 3 --json
qp next --json
Observe

Follow the presentation.

Check the current page and rendering or note state. Observe changes as NDJSON; use status to check readiness.

qp status --json
qp watch --json

Prepare your PDF

Export the slides. Include the notes.

Quick Presenter also works as a regular PDF presenter without AI. Create slides in your authoring tool, export a PDF, and use the presenter and audience windows. Editing stays in your authoring tool.

1. Export a display-ready PDF.

Use Keynote, PowerPoint, Google Slides, Marp, or LaTeX Beamer to prepare the deck. The exported PDF is the input to Quick Presenter.

2. Include accessible speaker notes.

A PDF export does not necessarily contain extractable notes. With Marp, keep notes in Markdown comments and export with --pdf-notes. Check the notes in Quick Presenter before presenting.

marp --no-config --pdf --pdf-notes talk.md --output talk.pdf
