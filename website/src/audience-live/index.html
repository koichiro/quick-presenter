How it works

A phone. A browser. A voice in the room.

Attendees need no dedicated app and no attendee account. Once the presenter starts Audience Live, joining takes three steps.

  1. ▦

    Scan the QR Code

    Scan the join code on the presentation screen, or open its join URL in your phone’s browser.

  2. ♡

    Send Reactions and Comments

    Tap a reaction or send a short comment while the talk continues.

  3. ▤

    Watch Them Appear Live

    Responses appear over the PDF slides in the Audience Window for the room to see.

Choose Your Connection

Open source. Your choice of hosting.

Local LAN

The app hosts the session on your trusted local network. Presenter and attendees share the same LAN; no external relay or relay account is needed.

Internet is not required. Wi-Fi isolation or firewalls may block joining. Local HTTP/WebSocket traffic is unencrypted.

Local setup guide

Self-hosted Relay

Run the open-source quick-presenter-relay server on your own infrastructure. You manage operations and HTTPS for remote access. Devices need access to your relay, not the same LAN.

Getting Started

Your first Audience Live session.

  1. Install Quick Presenter with Audience Live. Use the v3.0.0 RC1 testing package linked below and open a prepared PDF. The final release is pending.
  2. Choose your connection before turning it on. For LAN, select the LAN IPv4 address. For either relay, obtain its TOML settings and use Settings > Import settings while Audience Live is off. Settings > Reset returns relay settings to local hosting.
  3. Enable Audience Live. Click Audience Live ON. The Audience Window shows a join screen with a QR code and URL.
  4. Invite the audience, then present. Attendees scan the QR code and send comments or reactions in their browser. Advance once to show the PDF. Previous from PDF page 1 returns to the join screen.
  5. End the session. Click Audience Live OFF to end the session and invalidate its join link.

FAQ

Before you go live.

Do attendees need to install an app?

No. They scan a QR code or open the join URL in a browser. Attendees do not need an account.

Is an internet connection required?

Local LAN works without internet when devices can reach the presenter on the same network. Official Relay requires internet for both presenter and attendees. A self-hosted relay needs a network route from each device to that server.

How do Local LAN and Official Relay differ?

Local LAN uses the presenter’s computer as the server on the same trusted network. Official Relay is a hosted service reached over the internet, so attendees can use different networks. It requires a presenter account and ticket and is subject to the Shop’s service terms.

Can I self-host?

Yes. quick-presenter-relay is open source under Apache-2.0 and is available on GitHub and npm. You operate the server, configure HTTPS for remote access, and import the generated TOML settings into Quick Presenter.

Is it free to use?

Quick Presenter is GPL-3.0-only open source. Local LAN needs no relay subscription. The self-hosted relay is open source, but you provide its infrastructure. Official Relay Open Beta currently offers free tickets only; check the Shop for current conditions and limits.

Where can I send feedback or report a bug?

Use Quick Presenter GitHub Issues for app feedback, or Relay Issues for self-hosted server problems. Include the app version, OS, connection mode, and reproduction steps. Remove join URLs, tokens, and real attendee messages from reports.
