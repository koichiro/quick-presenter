Quick Presenter Privacy Policy

Effective date: October 1, 2026

Summary

Quick Presenter is a local PDF presentation tool. It does not collect, transmit, sell, or share personal information.

PDF files selected by the user are opened and processed locally on the user's device. Quick Presenter does not upload PDF files, PDF contents, rendered slides, speaker notes, thumbnails, or presentation activity to the developer or to third-party services.

Accounts, Advertising, and Analytics

Quick Presenter does not require an account or login. The app does not include advertising, tracking, behavioral analytics, or custom in-app telemetry.

Local Preferences

Quick Presenter may store local preferences on the user's device. The current app stores a recent-file list so speakers can reopen decks from the File menu.

The recent-file list stores PDF file paths only. It does not store PDF contents, rendered slide images, speaker notes, thumbnails, page history, or usage analytics.

File paths are stored as plain text in the platform configuration directory. Use File > Clear Recent Files to remove the saved list.

Store Purchases and Diagnostics

Microsoft Store purchases, payment information, and store account data are processed by Microsoft under Microsoft's own terms and privacy practices.

Quick Presenter does not add custom crash reporting. If Microsoft provides Store-managed crash or reliability diagnostics for a Store package, those diagnostics are provided by Microsoft as part of the Store and Partner Center experience, not by custom upload behavior in Quick Presenter.

Source, License, and Contact

Quick Presenter is open source software licensed under GPL-3.0-or-later. The source code is available at github.com/koichiro/quick-presenter.

For privacy questions or issue reports, use the project's public issue tracker at github.com/koichiro/quick-presenter/issues.
