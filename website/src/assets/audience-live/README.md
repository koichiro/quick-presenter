# Audience Live landing-page media

These are unmodified copies of the real macOS Audience Window recordings and
posters from [PR #561](https://github.com/koichiro/quick-presenter/pull/561),
source commit `312cae70ab8a970412cc102c17d2dffd2d9b916c` on
`codex/v3-readme-changelog-demos`. The original paths are
`docs/assets/audience-live/{flowing,bubbles}.{gif,jpg}`. They are checked in here
so this website PR builds from `main` without merging or modifying #561.

All four assets are provided under **GPL-3.0-only**, the repository's
[license](../../../../LICENSE). They use the repository-owned sample PDF,
synthetic Anonymous comments (six English, four Japanese), and repository
reaction artwork. No real attendee messages, join URLs, credentials, QR codes,
or presenter notes appear. No UI was reconstructed or retouched.

Both 960×510 GIFs contain 270 frames at 10 fps, 27 seconds, looping. The native
1024×576 capture was cropped by 32 pixels at the top to remove the macOS capture
indicator, then scaled, sampled, and palette-converted. Posters are real frames
at 8.4 seconds (flowing) and 17.6 seconds (bubbles). The source app is the published
v3.0.0 RC1 macOS Developer ID package, application commit
`3fd02c9a914b120a7eb4b7cd949ecc38e951c458`, executable SHA-256
`f30dfde1822249765e51efc2be3d223c6f6824ac61c224c0202fad511060aa0b`.
These local feature demos are not relay performance or platform qualification.
